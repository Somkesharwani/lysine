Lysine
A comprehensive Account & Reimbursement and Expense Management Solution designed to streamline the process of tracking expenses, managing reimbursements, and handling user accounts.

Overview
Lysine is a microservices-based platform that helps organizations and individuals:
Manage user accounts and authentication
Track expenses and spending
Process and manage reimbursement requests
Generate reports and analytics

Architecture
The project follows a microservices architecture with the following modules:

Core Modules
reimbursement-service - Handles reimbursement request processing, approval workflows, and payment tracking
openApi-service - RESTful API service with OpenAPI/Swagger documentation
common-lib - Shared libraries and utilities across services

Build System
buildSrc - Custom Gradle build configurations and plugins
gradle - Gradle wrapper and configuration files

Technology Stack
Language: Java
Build Tool: Gradle (Kotlin DSL)
Architecture: Microservices
